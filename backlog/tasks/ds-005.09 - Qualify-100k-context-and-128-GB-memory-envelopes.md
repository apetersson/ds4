## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Measure and document safe 100k-context configurations on the 128 GB M1 Ultra for Headroom128 and Quality128, plus SSD-streamed native reference operation. Include prefill peak, decode residency, vision encoder lifecycle, optional DSpark costs, KV policy, and failure margins.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Headroom128 and Quality128 target-only servers start with --ctx 100000 and complete deterministic long-context requests within their defined RAM safety margins.
- [ ] #2 Vision encoding plus 100k receiver prefill does not overlap tower/activation and peak receiver allocations beyond the documented envelope.
- [ ] #3 DSpark at 100k is tested only where the calculated and measured envelope is safe; otherwise startup rejects it with a specific alternative.
- [ ] #4 Native reference SSD streaming reports a validated cache-expert budget and either passes 100k or documents the maximum safe context from measured evidence.
- [ ] #5 Reports separate model files on disk, planned unified memory, measured process-tree peak, KV raw/compressed rows, buffers, resident model, expert cache, and prefill reserve.
- [ ] #6 Memory pressure, swap, thermal/power state, SSD throughput, prefill speed, decode speed, and recovery after unload are recorded.
- [ ] #7 A safety margin is retained for macOS and client processes rather than treating 128 GB as fully allocatable.
<!-- AC:END -->
