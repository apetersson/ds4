## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Add a dedicated generic-in-API DeepEncoderV2 preprocessor to libmtmd that exactly reproduces the trusted Python RGB, tiling, resize, normalization, and view-order behavior.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 RGB conversion, global-view-first ordering, integer crop boundaries, row-major crops, 1024x1024 bicubic resize, and (x-0.5)/0.5 normalization match the Python reference.
- [ ] #2 Tiling activates only at the reference threshold; grid choice minimizes aspect-ratio error and prefers more tiles on ties within the configured tile limit.
- [ ] #3 Output ordering and counts implement views*256+1 and cover 257, 769, 1025, and 1281 receiver rows without relying on an incomplete enumeration.
- [ ] #4 Golden portrait, landscape, square, threshold-boundary, aspect-tie, alpha, grayscale, and malformed-image fixtures compare pixels and crop metadata to the Python oracle.
- [ ] #5 Preprocessor has explicit image dimension/allocation/overflow limits and deterministic failures.
- [ ] #6 No model-specific public libmtmd API or llama-mtmd-cli flag is introduced.
<!-- AC:END -->
