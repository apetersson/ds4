## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Resolve a repository ID and optional branch, tag, or commit into an immutable Hugging Face commit before acquiring selected artifacts. Authentication and endpoint configuration must follow established HF conventions without exposing tokens in process arguments or logs.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Default revision resolution returns and records an immutable commit SHA before weight downloads begin.
- [ ] #2 All files for one launch are fetched from the same resolved commit even if the repository branch moves concurrently.
- [ ] #3 HF_TOKEN and existing Hugging Face authentication are supported without printing credentials or placing tokens in argv.
- [ ] #4 HF_ENDPOINT is honored consistently for manifest lookup and artifact acquisition.
- [ ] #5 Private/gated, missing repository, missing revision, authentication failure, network failure, timeout, and malformed API response produce distinguishable diagnostics.
- [ ] #6 Resolution can be exercised against a deterministic fake endpoint without downloading production weights.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Add a minimal HTTP transport/resolution boundary that resolves repository plus optional revision to an immutable commit, constructs every subsequent repository URL from that pinned commit and one normalized HF endpoint, discovers Hugging Face authentication without exposing credentials, maps distinct failure classes to stable diagnostics, and proves the behavior against a deterministic local fake endpoint without production-weight calls.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implementation keeps DS-001.04+ boundaries intact: it performs only Hub model-API revision resolution and immutable URL construction. It does not parse variants.json, transfer/resume/cache artifacts, verify hashes, or load models. Verification uses only a local deterministic fake endpoint and tiny API metadata.
