## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Synthetic ABI tests run in ordinary CI without production weights and cover parsing, placement, CPU/Metal parity, request mapping, sessions, and cancellation.
- [ ] #2 Production-weight tests cover terminal screenshots, natural images, charts, OCR, spatial questions, irrelevant-image controls, and adversarial prompt/image disagreement.
- [ ] #3 Correct-image accuracy exceeds defined thresholds and degrades materially for zero/shuffled controls, proving causal image use.

- [ ] #6 Text-only deterministic fixtures match the integration base and show no meaningful throughput or memory regression.
- [ ] #7 Peak process-tree memory confirms encoder allocations are released before receiver prefill on the 128 GB M1 Ultra.
