## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Extend llama.cpp conversion tooling with an MmprojModel path that consumes the exact DeepEncoderV2 tower, DeepSeek-V4 projector, and trusted config and emits one self-contained BF16 mmproj GGUF.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Converter accepts DeepEncoderV2-BF16.safetensors, DeepSeek-V4-0731-Projector-BF16.safetensors, and upstream-config.json without executing remote model code.
- [ ] #2 Output contains complete SAM ViT-B, convolutional neck, Qwen2 encoder/query, 896-to-4096-to-4096 projector, and view_seperator tensors.
- [ ] #3 Every tower/projector tensor remains BF16 and mapped tensor payloads are bit-identical to the represented source BF16 values; no F16 conversion or quantization occurs.
- [ ] #4 GGUF metadata uses standard clip keys where applicable and a documented deepencoder_v2_dsv4 projector/model key family for exact preprocessing/routing parameters.
- [ ] #5 Converter rejects missing, extra-required, duplicate, wrong-shape, wrong-dtype, and incompatible-config inputs with tensor-specific errors.
- [ ] #6 A deterministic manifest records source/output hashes, tensor counts/types, metadata, converter revision, and byte-level verification.
<!-- AC:END -->
