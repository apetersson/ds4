## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Risk-calibrated review found that token discovery can fall through from an explicitly configured but empty XDG cache to a stale legacy HOME token. Select exactly one Hugging Face token path by convention so lower-priority identities are never used.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 HF_TOKEN_PATH, HF_HOME, XDG_CACHE_HOME, and HOME token locations follow strict Hugging Face precedence without fallback after a higher-priority location is selected.
- [ ] #2 A deterministic regression proves an empty configured XDG token location does not send a populated legacy HOME token.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Select one effective token path before reading it, then add a fake-endpoint assertion that the lower-priority HOME credential is not transmitted when XDG_CACHE_HOME is configured.
<!-- SECTION:PLAN:END -->
