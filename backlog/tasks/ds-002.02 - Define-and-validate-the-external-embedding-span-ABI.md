## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Specify the in-memory and serialized contract used to inject externally produced image embeddings into DS4 cold prefill. The ABI must define route tokens, row count, hidden width, dtype, digest, token-span placement, ownership, error handling, and version compatibility independently of DeepEncoderV2.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The ABI version, magic, header bounds, route-token representation, F32 row layout, hidden width, row count, image digest, and byte order are documented.
- [ ] #2 Malformed magic, version, dimensions, row counts, route IDs, truncated payloads, trailing data, integer overflow, and non-finite embeddings fail before model execution.
- [ ] #3 The maximum accepted embedding payload is bounded relative to context and hidden size.
- [ ] #4 Payload ownership and cleanup are correct on success, cancellation, parse failure, backend failure, and server shutdown.
- [ ] #5 Parser tests include valid 257-, 769-, and 1281-token layouts and adversarial payloads.
- [ ] #6 The ABI can be tested with synthetic embeddings without Python, images, or vision weights.
<!-- AC:END -->
