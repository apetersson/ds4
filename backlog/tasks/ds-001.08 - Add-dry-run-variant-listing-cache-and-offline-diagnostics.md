## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Make large-model acquisition inspectable before transfer and operable from a complete cache without network access. Diagnostic output must be scriptable, accurately distinguish decimal download bytes from runtime memory, and make optional companion costs visible.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 --list-hf-variants fetches only catalog metadata and prints selector, profile, quantization, receiver bytes, optional companion bytes, and declared capabilities.
- [ ] #2 --hf-dry-run reports exact files, immutable revision, cached/missing state, per-role bytes, total required transfer, and total selected weight bytes without loading a model.
- [ ] #3 --hf-offline performs no DNS or network calls and succeeds only when the manifest and all requested artifacts for the pinned revision are complete and valid.
- [ ] #4 Dry-run distinguishes receiver-only, receiver-plus-vision, and receiver-plus-vision-plus-DSpark totals when those capabilities are known.
- [ ] #5 Human-readable output and a stable machine-readable form are covered by golden tests.
- [ ] #6 Diagnostics never classify support GGUFs as standalone receiver variants.
<!-- AC:END -->
