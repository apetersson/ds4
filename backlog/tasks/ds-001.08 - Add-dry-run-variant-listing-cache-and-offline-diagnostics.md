- [x] #3 --offline and --hf-offline perform no DNS/network and succeed only from a complete verified snapshot for requested roles.
- [x] #4 Dry-run distinguishes receiver-only, DS4 receiver+vision, DS4 receiver+vision+DSpark, and llama.cpp receiver+mmproj catalog totals.
