## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Extend the DeepSeek V4 quantizer planning logic so DSpark support-model tensors that are already valid packed MXFP4 can be preserved rather than rejected, dequantized, or coerced into an incompatible low-bit plan. Preserve only tensor roles and geometries that the runtime can execute.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The planner identifies eligible DSpark routed expert tensors by semantic role, source dtype, shape, block geometry, and runtime capability rather than filename heuristics alone.
- [ ] #2 Eligible native MXFP4 tensors receive an explicit preserve action with exact expected source/output bytes.
- [ ] #3 Ineligible MXFP4 tensors, mixed unsupported roles, wrong shapes, missing scales, and unknown namespaces fail with tensor-specific diagnostics.
- [ ] #4 No preserve rule broadens ordinary receiver quantization or changes plans for non-DSpark models.
- [ ] #5 Plan summaries report preserved tensor count/bytes and all other conversion actions deterministically.
- [ ] #6 Unit fixtures cover supported preservation, wrong role, wrong block shape, unsupported mixed plan, and legacy DSpark inputs.
<!-- AC:END -->
