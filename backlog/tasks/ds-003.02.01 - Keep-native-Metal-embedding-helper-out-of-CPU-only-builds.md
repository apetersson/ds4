## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The transplanted F32 Metal embedding helper calls GPU APIs even when ds4.c is compiled with DS4_NO_GPU, breaking the required CPU build.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 make -B cpu compiles and links successfully
- [x] #2 make -B all and make test-mxfp4-metal pass after the guard
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Compile the helper only for GPU-enabled builds, then rerun CPU, Metal, and full test gates.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
The CPU build failed because metal_graph_embed_token_hc was visible in DS4_NO_GPU compilation but ds4_gpu_embed_token_hc_tensor and ds4_gpu_tensor_write are intentionally undeclared there. Wrapped only this GPU helper in #ifndef DS4_NO_GPU. make -B cpu and make -B all pass; make test-mxfp4-metal passes. The broader make test limitations and unchanged Metal-kernel failures are documented on parent DS-003.02.
<!-- SECTION:NOTES:END -->

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Guarded the GPU-only native F32 Metal embedding upload helper from DS4_NO_GPU compilation. CPU and Metal builds plus the focused MXFP4 Metal suite pass; final fresh parent-scope reviewer returned exact ALL GOOD.
