## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Validate downloaded and cached artifacts before DS4 opens them, and define a trust boundary in which model repositories provide data and typed metadata only. Preserve useful cached files on recoverable failures while preventing stale or mismatched files from being loaded.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Every manifest-declared receiver and companion is checked against its required byte count and SHA-256 before model loading.
- [ ] #2 A cached hash or size mismatch fails closed, identifies the affected artifact, and provides a non-destructive recovery command.
- [ ] #3 Symlink escape, path traversal, special files, directories where regular files are required, and replacement races are rejected.
- [ ] #4 Resolved paths remain inside the immutable snapshot/cache root after canonicalization.
- [ ] #5 No Python module, shell command, auto_map entry, or executable downloaded from the model repository is automatically run.
- [ ] #6 Integrity tests cover valid files, truncated files, same-size corruption, symlink escape, manifest mutation, and concurrent replacement attempts.
<!-- AC:END -->
