## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Validate every selected receiver or companion before DS4 opens it. Enforce a data-only trust boundary while supporting runtime-specific representations of the same lossless BF16 vision weights.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Every downloaded receiver, tower, projector, config, and requested DSpark artifact is checked against manifest byte count and SHA-256 before loading.
- [ ] #2 The catalog records and tests source-to-mmproj BF16 tensor identity separately; DS4 does not infer mmproj trust from matching names or shared HF LFS objects.
- [ ] #3 Cached mismatch fails closed with a non-destructive recovery command and never falls back to a same-directory heuristic artifact.
- [ ] #4 Path traversal, symlink escape, special files, snapshot escape, replacement races, and manifest mutation are rejected.
- [ ] #5 No Python module, auto_map entry, shell command, encoder script, or executable downloaded from the model repository is automatically run.
- [ ] #6 Integrity tests cover valid, truncated, same-size corrupt, cross-variant substituted, mmproj-vs-raw-role-confused, symlink, and concurrent replacement cases.
<!-- AC:END -->
