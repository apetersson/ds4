## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Define the user-visible contract for resolving a Hugging Face model repository and catalog selector in ds4 and ds4-server. Scope includes accepted syntax, aliases, option precedence, conflicts, exit behavior, help text, and compatibility with existing local --model and --mtp paths. This task establishes behavior; it does not download model weights.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Both ds4 and ds4-server accept --hf OWNER/REPO:SELECTOR, and -hf is either accepted as a documented compatibility alias or rejected consistently with a documented rationale.
- [ ] #2 --model and --hf are mutually exclusive and fail before model allocation with a concise diagnostic.
- [ ] #3 --hf-revision, --hf-cache-dir, --hf-offline, --hf-dry-run, and --list-hf-variants have unambiguous documented semantics.
- [ ] #4 An omitted selector is accepted only when the manifest declares exactly one default; otherwise available selectors are listed without downloading weights.
- [ ] #5 Explicit --mtp remains supported and its precedence relative to a manifest-declared DSpark artifact is documented and tested.
- [ ] #6 CLI parsing tests cover valid selectors, malformed repository IDs, duplicate flags, missing arguments, and incompatible options.
<!-- AC:END -->
