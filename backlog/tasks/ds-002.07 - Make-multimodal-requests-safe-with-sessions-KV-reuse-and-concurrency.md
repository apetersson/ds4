## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Integrate external image spans with DS4 server scheduling and session/KV behavior. A visual request must never reuse incompatible token-only state or another image embedding, and concurrent requests must not cross-associate encoder output, prompt spans, cancellation, or response state.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Visual cold prefill bypasses token-only KV reuse unless the cache identity includes the complete image digest, layout, receiver fingerprint, and prompt tokenization.
- [ ] #2 Different images with identical text cannot reuse each other’s visual KV state.
- [ ] #3 The same image and exact prompt either reuse a correctly keyed state or deliberately recompute according to a documented policy.
- [ ] #4 Concurrent visual and text requests preserve request-local embeddings, errors, streaming output, and cancellation.
- [ ] #5 Batched-session mode either supports visual requests with isolation or rejects them before encoding with a documented limitation.
- [ ] #6 Continuation endpoints preserve the sampled receiver state without re-encoding or losing the original image identity.
- [ ] #7 Concurrency tests use distinct synthetic image embeddings and prove no cross-request contamination.
<!-- AC:END -->
