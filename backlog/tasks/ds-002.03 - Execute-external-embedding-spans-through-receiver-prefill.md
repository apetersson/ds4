## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Extend the engine cold-prefill path so selected token positions use caller-provided hidden rows while all other positions preserve ordinary token embedding lookup. Support the receiver backends needed for validation without altering decode behavior after the injected span.

<!-- AC:BEGIN -->
- [ ] #1 Injected rows replace only the declared image-token span and preserve route-token processing and ordinary token embeddings outside that span.
- [ ] #2 Span start, end, row count, context bounds, and hidden width are validated before graph execution.
- [ ] #3 CPU and Metal produce numerically consistent receiver logits for deterministic synthetic embedding fixtures within a documented tolerance.
- [ ] #4 Text-only prefill follows the original fast path without additional copies, allocations, or numerical changes.
- [ ] #5 Chunked prefill either supports the external span correctly across boundaries or rejects unsupported placement before execution with a clear limit.
- [ ] #6 External rows remain alive for the complete backend operation and are released before decode.
- [ ] #7 Tests cover span at beginning, middle, and end; chunk boundaries; maximum supported rows; cancellation; and backend error cleanup.
