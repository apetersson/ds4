## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Implement and isolate the converter path that preserves packed MXFP4 values and represents the remaining supported source tensors in exact-value F16, F32, and I32 GGUF types. Conversion must stream bounded working sets and must not silently requantize or dequantize protected tensors.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The output contains exactly the expected tensor count, names, shapes, byte counts, and type histogram for F32, F16, I32, and MXFP4.
- [ ] #2 Packed MXFP4 tensor payload bytes are copied or transformed losslessly according to a documented mapping with round-trip verification.
- [ ] #3 F16/F32/I32 tensors compare exactly to their source representation after the declared format conversion.
- [ ] #4 Unsupported source dtype, unknown tensor, missing tensor, duplicate tensor, shape mismatch, non-finite protected tensor, and truncated shard fail before final output publication.
- [ ] #5 Temporary output is atomic and an interrupted conversion cannot replace a previously valid GGUF.
- [ ] #6 Peak conversion RAM and temporary disk use are bounded and reported for the 48-shard source.
- [ ] #7 The converter can resume only at explicitly verified boundaries or restarts cleanly without trusting partial tensor data.
<!-- AC:END -->
