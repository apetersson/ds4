## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Plan and validate SSD-streamed execution of the approximately 153.4 GiB native reference GGUF on a 128 GB Apple Silicon host. Memory planning must reserve context, prefill, resident dense tensors, Metal buffers, and dynamic expert cache without pretending the whole model can be resident.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 --ssd-streaming skips full-model residency and warmup while retaining all always-needed dense/non-expert tensors required for correct execution.
- [ ] #2 --ssd-streaming-cache-experts accepts byte budgets such as 48GB and reports the split between prefill reserve and dynamic expert cache.
- [ ] #3 Planned and measured process-tree peak unified memory stay below a defined safe ceiling on the 128 GB M1 Ultra for the documented smoke context.
- [ ] #4 A 100k-context configuration either passes with recorded peak memory and latency or is rejected before allocation with a calculated minimum-memory diagnostic.
- [ ] #5 Expert cache fill, eviction, preload, cold mode, and full-layer retention never map spans outside the verified mixed GGUF.
- [ ] #6 Streaming output is semantically sane and deterministic enough to detect the prior multilingual garbage failure.
- [ ] #7 Resident-mode launch is documented for hosts with sufficient RAM and remains independent of streaming-specific state.
<!-- AC:END -->
