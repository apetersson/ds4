## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Support the native-preserving tensor types in receiver graph construction and execution, including F32 token embeddings and packed MXFP4 routed experts, without introducing implicit lossy conversion or breaking existing quantized profiles.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 F32 token embeddings execute correctly in all Metal graph paths used by prefill, decode, external embedding-span routing, and output staging.
- [ ] #2 F16/F32 dense tensor operations use supported kernels or explicit deterministic conversions whose precision and lifetime are documented.
- [ ] #3 MXFP4 expert tensors use the intended packed kernels and never fall through to IQ2 or incompatible repack paths.
- [ ] #4 CPU reference and Metal logits agree within a defined tolerance on small deterministic mixed-type fixtures.
- [ ] #5 Existing IQ2_XXS, Q4, and standard MXFP4 models retain their loader and numerical regression results.
- [ ] #6 Backend diagnostics identify unsupported pre-M5 Metal tensor APIs and the selected fallback without presenting fallback as native tensor-API acceleration.
- [ ] #7 No per-token full-weight conversion or unbounded duplicate tensor residency occurs.
<!-- AC:END -->
