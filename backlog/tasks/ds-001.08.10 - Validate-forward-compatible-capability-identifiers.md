## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Review 7 finding: arbitrary unknown optional JSON strings, including empty or comma-containing values, can make human declared-capability output lossy or ambiguous.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Unknown optional capability names must satisfy an unambiguous lowercase hyphenated identifier grammar; empty, comma-containing, or malformed identifiers fail parsing actionably.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Require nonempty lowercase alphanumeric capability segments separated by single hyphens before storing names, and add negative parser coverage.
<!-- SECTION:PLAN:END -->
