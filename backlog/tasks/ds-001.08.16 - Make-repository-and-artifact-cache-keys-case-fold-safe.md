## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Review 12 finding: repository cache components preserve case and artifact destinations append raw manifest paths, so case- or normalization-distinct valid identities collapse on case-folding filesystems and make verified snapshots unusable.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Repository and artifact cache identities use injective normalization-safe bounded path components; deterministic case- and Unicode-distinct repo/artifact fixtures remain independently usable online and offline.
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
Encode repository IDs and full artifact repo paths as lowercase byte-hex split into bounded directory components with fixed leaves, retain exact identities in sidecars, and add case/normalization collision coverage.
<!-- SECTION:PLAN:END -->
