## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Bound and secure all server-side image acquisition and encoder subprocess behavior. Local-file access must remain opt-in and localhost-oriented; network images must not become an SSRF primitive; temporary artifacts and child processes must be controlled under cancellation and shutdown.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Maximum encoded and decoded image bytes, dimensions, pixel count, redirects, transfer time, and encoder runtime are bounded.
- [ ] #2 HTTP image retrieval rejects loopback, link-local, private, metadata-service, unsupported scheme, and redirect-to-disallowed destinations unless an explicit unsafe development policy is enabled.
- [ ] #3 file: and server-local paths are disabled by default for non-loopback binds and cannot escape configured allow roots.
- [ ] #4 Temporary files use exclusive creation, restrictive permissions, validated paths, and guaranteed cleanup.
- [ ] #5 Encoder argv is constructed without shell evaluation and user-controlled values cannot become options or executable paths.
- [ ] #6 Client disconnect, request cancellation, timeout, SIGINT, SIGTERM, and server shutdown terminate/reap the child and release resources.
- [ ] #7 Security tests exercise decompression bombs, oversized data URLs, redirect chains, local path traversal, option injection, child timeout, and cleanup.
<!-- AC:END -->
