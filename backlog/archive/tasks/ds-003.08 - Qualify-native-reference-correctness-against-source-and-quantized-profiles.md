## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Establish that the final packaged native-preserving GGUF is operationally and semantically faithful enough to serve as the lossless/reference receiver. Compare deterministic outputs and intermediate signals against the source implementation and against Headroom/Quality quants while separating conversion bugs from runtime drift.

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A deterministic smoke suite covers plain completion, reasoning, code, multilingual text, long prefill, and output-token sanity.
- [ ] #2 Selected intermediate embeddings/logits or golden continuations compare against the source implementation under a documented tolerance and prompt template.
- [ ] #3 Native GGUF output does not exhibit the prior garbage-token behavior for Hello and other minimal prompts.
- [ ] #4 Resident and streamed modes agree within defined tolerances for prompts that fit both tested hosts/configurations.
- [ ] #5 Headroom128 and Quality128 comparisons report quality deltas without treating the quants as the source oracle.
- [ ] #6 Cold start, second start, interrupted streaming, unload/reload, and repeated deterministic generation are exercised.
- [ ] #7 Results record model hash, DS4 commit, backend, flags, context, peak memory, prefill/decode speed, and pass/fail rationale.
