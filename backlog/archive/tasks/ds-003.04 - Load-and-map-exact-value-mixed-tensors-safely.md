## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The loader accepts the verified native GGUF type histogram and maps every required tensor to the correct semantic field.
- [ ] #2 Required F32 token embeddings and other protected dense tensors retain their declared type rather than being coerced through F16-only assumptions.
- [ ] #3 MXFP4 routed tensors validate block divisibility, scale bytes, alignment, row geometry, and span bounds.
- [ ] #4 Unexpected type/shape combinations fail with tensor name, expected contract, actual type/shape, and file offset before GPU work.
- [ ] #5 All offset-plus-length and shape products are overflow-checked and confined to the mapped regular file.
- [ ] #6 Resident and SSD-streamed view planning cover every tensor span exactly once without gaps, overlap ambiguity, or stale pointers.
- [ ] #7 Malformed tiny GGUF fixtures exercise mixed types, boundary offsets, truncation, and missing tensors without requiring the production artifact.
