## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Provide the trusted DS4-side encoder bridge that loads the exact DeepEncoderV2 tower and projector, applies FlyCockpit preprocessing and tiling, emits the validated external embedding ABI, and exits before receiver prefill releases tower/activation memory. Model repositories may supply weights and declarative geometry but never executable encoder code.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The encoder implementation and DeepEncoderV2 module ship with the trusted DS4 branch or an explicitly installed DS4 vision package.
- [ ] #2 Tower and projector paths are explicit inputs; no auto_map, trust_remote_code, or repository Python is imported.
- [ ] #3 BF16 tower/projector weights remain BF16 through loading and computation where supported, while the DS4 interchange rows are deterministic F32.
- [ ] #4 Preprocessing exactly specifies RGB conversion, resize filter, normalization, tile-grid selection, view ordering, separator rows, and image digest.
- [ ] #5 The bridge reports selected device, dtype, layout, view count, encode duration, and output digest without logging image bytes.
- [ ] #6 Server resolution order for --vision-python, DS4_VISION_PYTHON, managed vision venv, and compatible python3 is documented and tested.
- [ ] #7 Encoder process, PyTorch/MPS memory, temporary payload, and source-image buffers are gone before receiver prefill starts.
<!-- AC:END -->
